System Architecture

Overview & Philosophy

Atlas is an engineering-grade scientific intelligence and technical reasoning workspace built by Vylex Technologies. Unlike standard conversational chat bots, Atlas pairs multi-model frontier inference with a deterministic execution runtime: live tools, computer vision, symbolic algebra, chemical formula rendering, and non-destructive code diffing.

Layer Technologies & Implementations Primary Function
Inference Layer OpenRouter API, SSE Streaming, Automated Failover Rotation High-throughput multi-model inference up to 1,000,000 context tokens.
Reasoning Layer 8 Investigation Modes, Chain-of-Thought <think> Parsers Structured hypothesis testing, mathematical derivations, and architecture reviews.
Execution Layer 26 Built-In Tools & Interactive Visual Widgets Deterministic API fetching, OCR extraction, QR generation, and symbolic/numerical math.
Rendering Layer KaTeX, mhchem, Highlight.js, 5-Tab Artifacts Canvas Rich scientific equation rendering and live HTML/CSS/JS sandbox previews.
Context Layer CSV/PDF Document Intelligence, Local Folder Reader, Unified Diff Engine Client-side dataset/PDF inspection and Git-style diffs with user-approved local file sync.

Reasoning Profiles

The 8 Specialized Investigation Modes

Atlas offers 8 dedicated investigation modes. Selecting a mode tunes the internal system instructions, reasoning depth, structure of explanations, and suggestion prompts.

Auto

Dynamically adapts reasoning depth and tone based on input complexity, balancing speed and depth.

Default adaptive prompt handling

Research

Focuses on literature synthesis, citation structure, contested scientific claims, and identifying experimental gaps.

Ex: "Synthesize current room-temperature superconductor claims"

Solve

Emphasizes step-by-step mathematical proofs, symbolic derivations, boundary conditions, and formal verification.

Ex: "Derive Navier-Stokes simplified boundary condition for laminar flow"

Build

Produces production-ready software code, architecture skeletons, refactoring proposals, and unit tests.

Ex: "Build a high-performance LRU cache in TypeScript with O(1) eviction"

Engineer

Analyzes distributed system bottlenecks, scalability limits, failover strategies, and edge-case failure modes.

Ex: "Deconstruct scalability limits for 10M req/min database sharding"

Experiment

Designs Monte Carlo simulations, statistical tests, hypothesis validation criteria, and control parameter matrices.

Ex: "Why does this experimental result contradict thermodynamic expectations?"

Reason

Structured logical analysis isolating premises, identifying fallacies, and testing constraint consistency.

Ex: "Deconstruct premise validity in quantum measurement interpretations"

Discover

Exploratory hypothesis generator connecting interdisciplinary ideas and unexplored technical territory.

Ex: "Formulate cross-domain applications between biological enzymes & battery catalysts"

Formula Engine

KaTeX & mhchem Scientific Rendering

Atlas natively parses and displays complex LaTeX mathematics and chemical formula equations directly in chat responses using KaTeX and the mhchem extension.

Write inline equations with single dollars $E = mc^2$ or multi-line block equations with double dollars $$\oint_{\partial \Omega} \mathbf{F} \cdot d\mathbf{S}$$. For chemistry, mhchem syntax \ce{...} renders complex equilibrium reactions and isotope notation:

// Calculus & Differential Equations: $$\nabla \times \mathbf{B} = \mu_0 \mathbf{J} + \mu_0 \varepsilon_0 \frac{\partial \mathbf{E}}{\partial t}$$ // Chemical Reaction with mhchem: $$\ce{2H2 + O2 -> 2H2O \quad \Delta H = -572 kJ/mol}$$ $$\ce{^{238}_{92}U -> ^{234}_{90}Th + ^{4}_{2}\alpha}$$
Workspace Context

Project Context, Document Intelligence & Safe Diff Engine

Attach datasets, PDFs, or local software directories directly in Atlas with client-side parsing and explicit user-approved file synchronization.

Feature How It Works Safety Guarantee
Local Folder Ingestion Link a project directory via the browser File System Access API (showDirectoryPicker) or attach files into the composer. Read-only browser ingestion; files remain on your machine unless included in a prompt or explicitly synced.
CSV & PDF Document Intelligence Client-side parsing computes automatic row/column counts and min/max/mean summary metrics for .csv files and extracts text from .pdf documents via PDF.js. Parsed directly in browser memory before prompt assembly.
Unified Diff Inspection & Sync Compare generated code against linked local files in a side-by-side unified diff view and click Apply to Local File to write approved updates. No automatic overwrites. Every file write requires explicit user approval in the browser.
Interactive Drawer

5-Tab Artifacts Canvas

Generated code blocks and documents open in a dedicated side-by-side workspace with five specialized views: Code (editable source with line numbers, copy, and download), Live Preview (sandboxed browser iframe for HTML/CSS/JS), Diff (line-by-line comparison against local files), Document (formatted Markdown reader), and Log (execution status console).

Production Infrastructure

Security & API Gateway

Atlas is designed with clear security boundaries to protect server credentials, validate model routing, and prevent network abuse.

Security Component Implementation File Protection Mechanism
Server Gateway & Optional BYOK src/services/openrouter.service.js The server's default OpenRouter API key stays strictly on the backend. Users may optionally store a personal OpenRouter key in browser localStorage, passed transiently via x-openrouter-key without server-side persistence.
Model Whitelist & BYOK Guard src/middleware/modelGuard.js Requests using the shared server key are restricted to the 7 curated models. Custom OpenRouter model IDs are permitted when a valid personal BYOK key is supplied.
Endpoint Rate Limiters src/middleware/rateLimiter.js Independent memory rate limiters for /api/chat, /api/chat/title, and /api/widget/execute prevent runaway request loops.
Deterministic Tool Dispatcher src/capabilities/index.js Only the 26 registered tools in UNIFIED_DISPATCHER can be invoked; Atlas does not expose an arbitrary server-side shell or code execution endpoint.
