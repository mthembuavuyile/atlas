# UI Fidelity & Minimalist Engineering Rules

- **Zero AI Embellishments**: Do NOT add floating pill badges, glowing pulsing dots, decorative AI widgets, or unnecessary visual clutter.
- **Model Badges**: Always omit "FREE" from model badges (use `AUTO`, `1.05M`, `1M`, `262K`, `256K`, etc.). Never append "FREE".
- **Design Integrity**: Strictly preserve what the user built. Do not invent new UI components or modify established layout structures without explicit instructions.
- **Dynamic Greetings**: Keep greetings natural, temporal, and contextually aligned to investigation modes. Avoid clumsy robot-like phrasing.
