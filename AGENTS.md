# Atlas Developer & Agent Guidelines

## Strict UI Fidelity
- **No Unsolicited Embellishments**: Never add floating decorative pills, glowing dots, or AI gimmicks. Preserve the clean, focused interface created by the user.
- **Model Badging**: Model badges must NEVER include the word "FREE" (e.g. use `AUTO`, `1.05M`, `1M`, `262K`, `256K`).
- **Dynamic Greetings**: Keep greeting text natural, time-aware, and aligned with active investigation modes.
- **Preserve User Code**: Always respect existing architecture, HTML structures, CSS variables, and styling tokens.
